# Loves Me, Loves Me Not — Web Edition

A browser-playable pixel-art flower game adapted from the Pygame concept.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will appear in Settings → Pages.

## Controls
- Tap/click a petal to pick it.
- Sound button toggles synthesized sound effects.
- Fullscreen button toggles fullscreen.
- `M` toggles sound, `R` replays, `F11` toggles fullscreen, `Esc` returns to title.

No external images, fonts, or audio files are required.
